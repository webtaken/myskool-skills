# About template (Skool, max 1,000 characters, plain text)

Order that works: headline with a deadline → contrast → the owner's story in
one or two lines → the method by name → what is inside, counted → who it is
for and who it is not → cancel anytime + sign-off.

```
[Promise in one line: result + for whom + by when]

If today [state A in their words], here [what changes].
This is not [what they already tried]. It is [the method, by name].

[Owner's story in 1–2 lines. Missing → "[your story: …]"]

Your first month:
✅ Week 1: …
✅ Week 2: …
✅ Week 4: …

What's inside ⬇️
✅ [N] live calls a month …
✅ [N] courses · [N] lessons …
✅ [N] challenges …

For you if […]. Not for you if […].

[Proof in 1–2 lines, if it exists]
[Price and guarantee, if shown]
[Call to action: what to do now]
```

Rules:

- Plain text. Emojis only if the community uses them; ✅ for counted items.
- Every number is real and countable today. Planned things say "from [month]".
- No story or number available → keep the bracket visible, never invent.
- Count characters including line breaks. Show the count under the text.
- Short description: about 120–150 characters, result + deadline + "without
  [objection]".

## Pinned posts

1. **Welcome** — what this community is in two lines, the first task to do
   today (under 20 minutes), where to introduce yourself.
2. **The main route** — how to start the entry challenge or phase 1, and
   what the first win looks like.
3. **Rules and culture** — three short rules and where to ask for help.

Each: a title of 3–8 words, a body under 150 words, one clear next step.
