# Onboarding messages

Plain text, under 80 words each, creator's voice, one action per message.
`{first_name}` is the only variable; everything else is written out.

| Moment | Channel | Job of the message |
|---|---|---|
| On joining | Skool AutoDM (sent by Skool 1–5 min after joining; set in Settings) | Welcome + the first task for today + where it lives |
| Day 1 | Post prompt in the intros category (if used) | Introduce yourself with 3 fixed lines, so intros are easy to answer |
| Day 3 | DM | "How is [first task] going?" + one concrete help |
| Day 7 | DM or post | Celebrate the first win — or, if there was none, offer the 3-day way back |
| 5 quiet days | DM | No guilt. One 5-minute action to come back |

## Shapes

**On joining**
```
Hola {first_name}! Qué bueno tenerte aquí.
Tu primera tarea es de hoy y toma [N] minutos: [task].
Está aquí: [lesson or post link]
Cuando la tengas, publícala en [category]. Ahí te leo.
```

**Day 3**
```
{first_name}, ¿cómo vas con [first task]?
Si te trabaste en [most common block], prueba esto: [one tip].
Respóndeme con una palabra y te ayudo.
```

**Day 7 — did it**
```
{first_name}, primera semana hecha: [what they did].
Lo que sigue: [next step, by name]. Empieza [day].
```

**Day 7 — did nothing**
```
{first_name}, la primera semana se va volando, pasa.
Tengo una vuelta corta para ti: [re-entry, 3 days, 5 min a day].
¿Empezamos mañana?
```

**5 quiet days**
```
{first_name}, sin presión: [5-minute action] y ya estás de vuelta.
Aquí: [link]
```

Rules:

- Links only to lessons, posts or events that exist. Missing → `<link to …>`
  left visible.
- The AutoDM is one text for everyone: no route-specific promise in it.
- Write them in the community's language; the shapes above are Spanish
  examples.
- DMs can't be deleted. Any message sent through MySkool goes one by one
  through the approval protocol.
