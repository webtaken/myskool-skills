# `.myskool/faq.md` — community knowledge base format

One file, plain markdown, written in the community's language. The answer desk
reads it before drafting; other MySkool skills (urgent radar, welcome intros)
reuse its links. Keep it short enough to read in one pass: 15–60 entries.

```markdown
# FAQ · <group name>
Updated: 2026-10-01 · Sources: 34 answered threads

## Start here
- Start here post: <url>
- Support questions: <where, e.g. category "Soporte" or DM to @coach>
- Program steps: Módulo 0 instalar Claude Code → Módulo 1 primer agente → …
- Live calls: <day, time, timezone, link>

## Access & downloads
### No puedo descargar los recursos del módulo 3
A: Los archivos están en Classroom → Módulo 3 → "Recursos". Si el botón no
responde, ábrelo desde la computadora (en el móvil Skool no descarga ZIP).
Links: <url>
Source: <thread url> · answered by @lucia-ramos-1234 · 2026-09-12
Seen: 4 times

## Tools & setup
### No me deja instalar Claude Code en Windows
A: …
```

Rules:

- Group entries under 4–8 headings by member problem, not by your taxonomy.
- `###` = the question as members phrase it (most common wording).
- `A:` = the creator's/team's answer in their own words, trimmed. Never add
  facts nobody from the team said.
- Keep links exactly as the team posted them.
- `Seen: N` = how many threads asked it; sort entries by it inside a heading.
- Mark entries older than 90 days that mention dates, prices or versions with
  `(verify)` — they may be stale.
- Never include DM content, member emails/phones, or refunds/billing promises.
